# Blog Content

This directory is the source of truth for JeniDevOps articles.

## Authoring

- Create one `.mdx` file per article.
- Use the metadata contract in `_template.mdx`.
- Use a unique lowercase slug.
- Keep drafts marked `draft: true` until they are reviewed.
- Use official documentation for technical references.
- Label lab-tested examples, production experience, and conceptual examples accurately.
- Do not include credentials, private infrastructure details, customer data, or confidential company information.

## Publishing

The first-party article on jenidevops.in is the canonical publication. After it is reviewed and published, it can be adapted for Hashnode and AWS Builder Center. Set the original/canonical URL on destination platforms where supported.

See the repository-root `BLOG_ARCHITECTURE.md` for the publishing workflow and technical decisions.
