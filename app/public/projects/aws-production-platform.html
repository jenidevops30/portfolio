PROJECT 01

● BUILDING

AWS Production Platform

A production-style AWS platform designed to demonstrate secure networking, high availability, load balancing, monitoring, automation and failure recovery.

AWS Terraform ALB Auto Scaling RDS CloudWatch

OBJECTIVE

Build infrastructure that can be operated, tested and recovered.

The goal is not simply to deploy an application. The platform will be deliberately tested under failure conditions to understand how each layer behaves and how incidents can be diagnosed.

ENGINEERING AREAS

Networking

VPC, subnets, routing and security boundaries.

Compute

Linux application servers, EC2 and Auto Scaling.

Load Balancing

ALB, target groups and health checks.

Database

Private RDS architecture and controlled database access.

Observability

Metrics, logs, alarms and operational troubleshooting.

Reliability

Failure testing, recovery and availability analysis.

FAILURE LAB

Build → Break → Troubleshoot

01 — EC2 Failure

Terminate an application instance and observe recovery behavior.

02 — Health Check Failure

Break the application health endpoint and investigate target health.

03 — ALB 502

Investigate failures between the load balancer and application.

04 — Database Connectivity

Diagnose security-group and database connectivity problems.

05 — High CPU

Generate controlled load and investigate resource saturation.

STATUS

Currently building

This project is being developed progressively. Infrastructure, monitoring, failure testing and implementation evidence will be added as each stage is completed.
